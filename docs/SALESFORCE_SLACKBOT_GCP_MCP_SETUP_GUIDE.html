⚙️ Exact Salesforce Configurations Required

Here is the definitive checklist of every setting, metadata item, and security permission required on Salesforce to connect with the GCP Slackbot and Salesforce MCP.

Configuration 1

Remote Site Settings & CSP

Allow outbound HTTP callouts from Apex to GCP and Slack:

  • GCP Slackbot Endpoint:
    https://slack-gemini-agent-xyz.a.run.app
  • Slack API Endpoint:
    https://slack.com
Setup Path: Setup → Security → Remote Site Settings → New Remote Site.
Configuration 2

OAuth 2.0 Connected App

Allows the GCP Slackbot to authenticate into Salesforce and invoke the Salesforce Custom MCP server:

  • Connected App Name: Slackbot_GCP_Gateway
  • OAuth Scopes:
    • api (Access and manage data via REST)
    • refresh_token, offline_access (Long-lived session)
  • Permitted Users: Admin approved users are pre-authorized.
Generates the SF_CLIENT_ID and SF_CLIENT_SECRET needed by GCP.
Configuration 3

Custom Fields on User Object

Permanently caches identity to ensure <5ms zero-reconnect daily logins:

  • Slack_User_Id__c (Text 30)
  • Slack_DM_Channel_Id__c (Text 30)
  • Slack_Connected_Email__c (Email)
  • Slack_Pairing_Code__c (Text 20, Optional)
Grant Field-Level Security (FLS) Read/Edit to all CSM profiles.
Configuration 4

Salesforce MCP Server Setup

The hosted MCP server in Salesforce (LearnDCAgentMCPServer) exposes tools to external clients:

  • Endpoint URL:
    /platform/mcp/v1/custom/LearnDCAgentMCPServer
  • Exposed Tools:
    • search_accounts
    • query_snowflake
    • create_account_task
Configuration 5

Lightning App Page Placement

Deploying the chat interface for the CSM:

  • Open Account Record Page in Lightning App Builder.
  • Drag the slackBotAgent LWC into the right-hand utility sidebar or tab.
  • Pass recordId context so the bot knows the active customer account.
Configuration 6

Visualforce Popup Bridge (Optional)

Included in the package for enterprise popup OAuth fallback:

  • SlackOAuthCallback.page
  • SlackOAuthCallbackController.cls
  • Enables 1-click popup authorization closing via window.opener.postMessage.

2. Slack App Bot Permissions (OAuth & Permissions)

Ensure the Slack App (test_agent_app) in workspace AI Studio Agent with Slack has the following Bot Token Scopes:

  • chat:write — Allows sending AI responses and summaries.
  • im:history & im:read — Reads 1-on-1 private DM thread history.
  • im:write — Initiates 1-on-1 private DMs with CSMs.
  • users:read & users:read.email — Resolves CSM email to their unique Slack ID.
  • reactions:write & reactions:read — Handles thread pinning with pin reactions.

3. 1-Command GCP Cloud Run Deployment

Deploy the agent directly from the project directory using Google Cloud CLI:

gcloud run deploy slack-gemini-agent \
    --source . \
    --region us-central1 \
    --allow-unauthenticated \
    --set-env-vars SF_CLIENT_ID=PlatformCLI,GEMINI_MODEL=gemini-3.6-flash

🚀 CSM End-to-End User Experience Walkthrough

Here is the exact step-by-step experience for a Customer Success Manager (e.g., Summo CSM), highlighting how frictionless the connection and daily usage are.

Step 1 — First Login

Initial Open (Unconnected State)

The CSM opens Salesforce and navigates to customer Edge Communications.

  • The LWC loads in <100ms.
  • Badge shows: Slack: Sign in with Slack 🟡
  • Input placeholder: "🔒 Sign in with Slack to start chatting..."
  • Thread history is 100% empty (Zero history leak from other CSMs).
Step 2 — Handshake

1-Click OAuth Redirect Handshake

The CSM clicks "Sign in with Slack" directly in Salesforce:

  • Salesforce automatically retrieves the CSM's email (UserInfo.getUserEmail()) — zero manual typing required.
  • Redirects / opens popup to GCP (/auth/login) → redirects to official Slack consent screen.
  • CSM clicks "Accept / Allow" on Slack.
  • Slack redirects to GCP callback (/auth/slack/callback) which provisions private DM D0BUNTVJCQJ and updates Salesforce.
  • Window closes automatically, status turns Connected 🟢, and composer unlocks!
Step 3 — Interactive Chat

AI Chat with Live MCP Tools

The CSM types prompts or clicks quick action chips:

  • CSM clicks ⚡ /account-brief: Gemini queries the Salesforce MCP server, synthesizes CRM vitals, and returns an executive briefing card.
  • CSM clicks ❄️ /snowflake: Queries Snowflake data warehouse for live Health Score (85/100) and churn telemetry.
  • CSM instructs: "Schedule a follow-up task for next Tuesday": Agent asks for confirmation before logging the Task!
Step 4 — Slack Mobile Continuity

True Bi-Directional Sync

The conversation is mirrored in Slack:

  • The CSM leaves their laptop and opens Slack on their phone.
  • Inside the 1-on-1 DM with the bot, the exact conversation thread is visible.
  • The CSM replies directly in Slack: "Also notify the primary contact".
  • Returning to Salesforce, the LWC thread shows their Slack reply synchronized!
Step 5 — Day 2+

Zero-Reconnect Experience

Next morning, the CSM logs into Salesforce:

  • No login prompts. No pairing dialogs.
  • Salesforce retrieves User.Slack_DM_Channel_Id__c in <5ms.
  • Badge shows Slack: Connected 🟢 immediately.
  • CSM resumes chatting immediately.
Step 6 — Direct Thread Deep-Link

1-Click Slack Thread Navigation

Every conversation bubble contains a direct permalink:

  • CSM clicks Slack ↗ or 💬 View in Slack History.
  • Browser deep-links to:
    https://slack.com/archives/D0BUNTVJCQJ/p178851...
  • Expands the thread sidebar in both Slack Web and Slack Desktop.

🔒 Enterprise Security, Data Isolation & Governance

Why this architecture meets stringent enterprise privacy and compliance requirements.

Security Area Traditional Risk Our Architecture Safeguard
Cross-User History Leak CSM B opens Account page and sees CSM A's confidential Slack chats. 100% Strict User Scoping: Left sidebar queries enforce CreatedById = :currentUserId. If unauthenticated, returns empty list [].
Private DM Segregation All chats posted to a shared bot channel where entire company sees them. Isolated 1-on-1 DMs: Every CSM has their own private DM (D0BUQS5V68Z vs D0BUNTVJCQJ).
Employee Offboarding Employee leaves company, but Slack credentials remain active. Single-Point Revocation: Deactivating the Salesforce User instantly blocks LWC access and invalidates Connected App sessions.
Account Reassignment Account transferred to new CSM; historical threads expose predecessor's private notes. User-Bound Scoping: New CSM receives clean workspace thread; Gemini AI generates an instant /account-brief handoff summary.
High Availability GCP service outage stops all Salesforce account co-piloting. Graceful Dual Fallback: If GCP endpoint is offline, Apex automatically falls back to native Apex + Gemini MCP server execution.
